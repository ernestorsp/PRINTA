# ORDENES

Aplicación para organizar los pedidos de Printacrea.

## Objetivo
- HOME con resumen visual de pedidos pendientes y prioridades por fecha límite.
- Órdenes con el nombre del cliente como dato principal.
- Número de orden opcional.
- Origen: TikTok, Shopify o Zelle.
- Fecha de orden editable, con fecha actual por defecto.
- Plazos internos: TikTok 2 días hábiles; Shopify 3; Zelle 3.
- Estados: Pendiente, Lista para envío y Enviada.
- Producto, indicaciones y múltiples imágenes.

Base de datos: Google Sheet PRINTA, pestaña ORDENES.
